## About 잇다

잇다는 블록체인 기반 프리랜서 거래 플랫폼입니다. 프리랜서 거래를 막는 것은 실력이 아니라 불신이라고 믿습니다. 잇다는 의뢰인과 프리랜서가 처음부터 서로를 믿고 시작할 수 있도록, 거래의 처음부터 끝까지를 하나의 흐름으로 묶습니다.

- 한 번 기록되면 누구도 바꿀 수 없는 **블록체인 계약서**.
- 대금을 먼저 예치하고 작업이 끝나면 정산하는 **에스크로 결제**.
- 견적서 작성부터 전자 서명까지 이어지는 **계약 흐름**.
- 거래의 모든 과정을 한곳에서 나누는 **실시간 채팅**.
- 거래가 끝난 뒤 남기는 **리뷰와 포트폴리오**.

잇다는 대금 미지급, 계약서 분쟁, 검증되지 않은 상대라는 프리랜서 거래의 세 가지 불안을 기술로 해결합니다.

## Repositories

- [23D-Web](https://github.com/twenty-threeD/23D-Web) — Next.js 기반 웹 클라이언트.
